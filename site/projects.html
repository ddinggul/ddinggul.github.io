Selected projects 주요 프로젝트

Research, made runnable — pipelines and prototypes across speech, NLP, and language learning. 연구를 동작하는 코드로 만듭니다. 음성, NLP, 언어 학습을 아우르는 파이프라인과 프로토타입입니다.

speech · ongoing

Prosody Analysis with Contrastive Learning

Analysis of L1 and L2 prosodic patterns using mel-spectrograms, TextGrid-based alignment, and contrastive learning. 멜 스펙트로그램, TextGrid 기반 정렬, 대조 학습을 활용해 모어 화자와 제2언어 학습자의 운율 패턴을 분석합니다.

nlp · pipeline

Grammar Correction & Sentence Evaluation

A T5-based sentence correction and evaluation pipeline trained on learner language data to provide context-sensitive grammatical feedback. 학습자 언어 데이터를 활용해 구축한 T5 기반 문장 교정·평가 파이프라인으로, 문맥을 고려한 문법 피드백을 제공합니다.

llm · narrative

LLM-based Narrative Structure Modeling

A GPT-based project for analysing and summarizing narrative structure using Vogler's 12-stage Hero's Journey. Vogler의 영웅 여정 12단계를 바탕으로 서사 구조와 전개를 분석·요약하는 GPT 기반 프로젝트입니다.

app · mvp

AI Vocabulary Learning System

An English vocabulary learning prototype based on principles from Suggestopedia, implemented with a Flask backend and an iOS-based MVP. Suggestopedia의 학습 원리를 참고해 설계한 영어 어휘 학습 프로토타입입니다. Flask 백엔드와 iOS 기반 MVP로 구현했습니다.
